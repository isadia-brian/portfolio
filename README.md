## Portfolio Website 🌟

A modern, performance-focused developer portfolio built with Next.js and Tailwind CSS. Designed to showcase my projects.

---

#### 🚀 Features

- Responsive, mobile-first design
- Lightning-fast performance (SSR/ISR)
- Smooth animations and interactions
- SEO-optimized with dynamic metadata
- Dark/light mode toggle

#### 🛠️ Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS + tailwind-merge
- **Icons**: Lucide React
- **UI**: Shadcn/ui components
- **Tooling**: TypeScript, ESLint, Prettier

#### 🏁 Getting Started

_Prerequisites_:

- [Node.js](https://nodejs.org/) installed on your machine

```bash
git clone https://github.com/isadia-brian/portfolio.git
npm install
npm run dev
```
